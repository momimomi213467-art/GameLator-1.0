# GameLator 1.0

**GameLator 1.0** is an Android application that lets you run Windows (x86_64) applications and games using Wine and Box86/Box64.

It is based on the excellent open-source project **[Winlator](https://github.com/brunodev85/winlator)** by BrunoSX, rebranded and with a redesigned user interface inspired by the PlayStation 5 home screen.

## Features (planned / in progress)

- Run Windows games and apps on Android
- Beautiful PS5-inspired UI (dark theme, large cards, horizontal game rows, trophies style, etc.)
- Full rebranding from Winlator → GameLator 1.0
- Automatic APK builds via GitHub Actions

## Status
